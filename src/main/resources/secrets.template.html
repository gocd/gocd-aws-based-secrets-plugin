The region to use for signing and token endpoints.

AWS credentials are searched in this order:

  1. Statically configured credentials - in plugin configuration
  2. Environment Variables - AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY
  3. Java System Properties - aws.accessKeyId and aws.secretAccessKey
  4. Instance profile - (recommended) Instance profile credentials delivered through the Amazon EC2 instance metadata service (IMDS)

Leaving Access Key and Secret Access Key blank is recommended. When the GoCD server runs on AWS, prefer granting it an IAM instance/task role and letting the plugin auto-detect those credentials via the chain above, rather than configuring long-lived static credentials here. Providing an AccessKey and SecretAccessKey disables auto-detection and uses those static credentials instead. Read more about AWS credentials

Required permissions: Credentials or roles must have permissions to make the following api calls.

secretsmanager:GetSecretValue secretsmanager:DescribeSecret secretsmanager:ListSecrets secretsmanager:ListSecretVersionIds

{{ GOINPUTNAME[AssumeRoleArn].$error.server }}

Optional. If an Assume Role ARN is provided, the resolved or supplied credentials above are used only to sts:AssumeRole the supplied role, and the temporary credentials of the assumed role are used for all Secrets Manager API calls. In that case the required permissions should be granted to the assumed role rather than to the original credentials. Leave blank to use the resolved credentials directly.

When assuming the role, the plugin always supplies an external ID of gocd:server-id:<server-id>, where <server-id> is the unique ID GoCD generated for this server (the serverId attribute in Admin > Config XML). The role's trust policy can use a StringEquals condition on sts:ExternalId to ensure only this GoCD server can assume the role; without such a condition the external ID is ignored. 

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": {
        "AWS": "arn:aws:iam::111111111111:role/gocd-server-instance-role"
      },
      "Action": "sts:AssumeRole",
      "Condition": {
        "StringEquals": {
          "sts:ExternalId": "gocd:server-id:<server-id>"
        }
      }
    }
  ]
}
